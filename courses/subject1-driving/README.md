# 科目一驾考宝典 · 学练考一体教学课程

> 面向 **MetaPilot 交互式学习平台** 的完整课程包（导入后即成为独立「库」）。
> 目标：按「学 → 练 → 考」闭环学习，科目一稳定 **95+ 分**。

## 一、课程能帮你达到什么效果

本课程按 **95+ 分目标** 设计，覆盖科目一考试大纲全部七大项，直击最高频考点：

- **记分规则（占比最高的核心大分）**：完整覆盖 2022-04-01 起施行的公安部令第163号
  《道路交通安全违法行为记分管理办法》五档记分（12/9/6/3/1），并内置「#️⃣ 易混对照」。
- **数字大分题**：限速表、高速公路分车道限速、能见度 261/145/520、车距、警告标志距离等。
- **图题大项**：标志标线图鉴、交警手势、仪表指示灯——全部可交互训练。
- **全真模拟**：100 题（40 判断 + 60 单选）、每题限时（判断 22s / 单选 30s）、90 分合格，
  与真实机考一致。

## 二、使用方法

### 方式 A：导入 MetaPilot（推荐，享受完整学练考体验）

1. 启动后端与前端（见仓库根 README）；
2. 客户端「我的库」→「导入课程包」→ 选择本目录打包的 `zip` 或直接选择目录；
3. 在「科目一驾考宝典」库中打开课程「科目一 · 学练考一体教学课程」开始学习。
   - 交互块支持：高度拖拽 / 全屏 / 限时答题 / 动态交互 AI 评判。
   - 学习进度、学完打勾、错题回看由平台自动记录。

### 方式 B：直接打开交互组件（浏览器直开，单机可用）

`interactives/` 下的 HTML 全部**自包含、零外部依赖、离线可用**，双击即可在浏览器中练习：

| 组件 | 功能 |
|---|---|
| `self_check.html` | 10 题摸底自测，测完自动推荐学习路线 |
| `points_trainer.html` | 记分分类训练器（行为 → 12/9/6/3/1 档位） |
| `speed_trainer.html` | 限速数字训练 + 能见度口诀补全 |
| `signgallery.html` | 标志标线图鉴（SVG 绘制）+ 猜含义自测 |
| `gesture_quiz.html` | 交警手势学习 + 测验 |
| `highway_sim.html` | 高速公路情景模拟（9 站连续决策 + 安全分） |
| `dashboard_lamp.html` | 仪表指示灯学习 + 测验 |
| `mnemonic_cards.html` | 口诀记忆卡（翻转背诵 + 测验） |
| `accident_scenario.html` | 事故处置情景演练（**动态交互**：决策写入评判上下文，可在平台内提交 AI 评判） |

> `accident_scenario.html` 依赖 MetaPilot 动态交互运行时（`postMessage` 埋点）获得 AI 评判；
> 直接浏览器打开时可体验完整决策流程与本地评分，AI 点评需在平台内使用。

## 四、内容口径与准确性

- 记分规则 ✅ 依据 2022-04-01 施行的《道路交通安全违法行为记分管理办法》（公安部令第163号）五档口径；
- 处罚与刑事责任 ✅ 依据《道路交通安全法》（2021 修正）与《刑法》第 133 条；
- 限速 / 车道 / 能见度 / 让行 / 灯光 ✅ 依据《道路交通安全法实施条例》；
- 考试形式 ✅ 100 题、45 分钟、90 分合格、判断题+单选题（多选题属于科目四）。

> 课程内容为学习辅助材料，非官方出版物；如遇冲突请以当地车管所与考试题库为准。
> 口诀为记忆辅助（帮助快速回忆数字与档位），正式考题以规范表述作答。

## 五、目录结构

```
courses/subject1-driving/
├── manifest.json              # 课程包清单（生成物，勿手改）
├── README.md                  # 本文件
├── interactives/              # 9 个自包含交互组件（HTML/CSS/JS 零依赖）
└── scripts/                   # 课程生成脚本（改内容后重新生成 manifest）
    ├── build.py               # 块/容器构建 helpers
    ├── content_ch1_6.py       # 第 1-6 章
    ├── content_ch7_12.py      # 第 7-12 章
    ├── content_exam.py        # 第 13 章冲刺 + 第 14 章全真模拟卷
    └── seed_subject1.py       # 主入口：生成 + 校验 manifest.json
```

## 六、重新生成课程包

修改 `scripts/` 下任一内容文件后：

```bash
python courses/subject1-driving/scripts/seed_subject1.py
```

脚本会重新生成 `manifest.json` 并自动校验：块类型、选择题答案越界、
交互文件引用完整性、题目非空等。

为什么需要自适应高度？

  • 旧版交互块使用固定 height，内容超出时会被截断或留白；
  • 现在 iframe 加载后会自动测量内容高度并撑开组件，默认就能看到全部内容；
  • 制作动态页面（canvas / 动画 / 列表）时，内容变化高度也会被实时跟踪（MutationObserver + 轮询兜底）。

自由拖拽与全屏

  • 组件底部有拖拽手柄，按住上下拖动即可调整高度（200px ~ 1200px）；
  • 拖拽一次后转为「手动模式」，不再自动跟随内容高度；
  • 右上角按钮随时切换全屏，全屏时高度自适应撑满视口。

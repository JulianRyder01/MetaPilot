# AI 洞察插件（ai_insight）

> 插件 id：`ai_insight`。对**库文档（库 / 文档集 / 文档）与软链接本机目录（整个挂载或挂载内任意路径）**
> 多粒度建立向量索引，用 AI 查阅资料间的联系，按**四种思考模式**生成回答、建议或图表/课程。
> 使用入口：顶栏导航「AI 洞察」。
>
> 本插件替代并删除了原「个人知识库（knowledge_base）」插件；原有功能（多源索引、问答溯源）全部包含，
> 并新增文档集/文档粒度、挂载内路径选择与洞察规划生成。

## 1. 原理

```
资源树（库 → 文档集 → 文档；软链接挂载 → 挂载内路径）
  → 选中项文本化（小节 / Markdown 标题分段）→ Qwen3-Embedding（本地，0.6B / 4B）→ 向量
用户输入 → 同模型编码 → 余弦相似度 top-k 检索（多数据源合并）
检索结果拼入提示词 → MiniMax-M3 按所选思考模式生成（要求标注 [来源N]）
「洞察规划」→ 多轮 agent 推理（分析联系 → 批判反思 → 生成结构）→ 创建图表/课程到库
```

- 索引按数据源独立存储：`backend/data/ai_insight/<key>/vectors.npy` + `meta.json`
- key 规则：`lib_<库id>` / `col_<文档集id>` / `doc_<文档id>` / `sym_<挂载id>`（整个挂载）/ `sym_<挂载id>_<路径hash>`（挂载内路径）

## 2. 数据源（多粒度，选择灵活）

| 类型 | 内容 | 索引单元 |
|---|---|---|
| `library`（库） | 库下全部文档集 → 文档 → 小节 | 每个小节一段 |
| `collection`（文档集） | 单个文档集下的全部文档 | 每个小节一段 |
| `document`（文档） | 单个文档的全部小节 | 每个小节一段 |
| `symlink`（本机目录） | 整个挂载根，或挂载内任意目录/文件，递归扫描文本文件（`.md/.markdown/.txt/.text/.rst`） | 按 Markdown 标题分段；无标题则整文件一段 |

资源树经 `GET /resources` 返回，每个节点附索引状态；软链接挂载内路径经
`GET /resources/symlink/{mid}/tree` 懒加载浏览，可精确选择目录或单个文件。

## 3. 四种思考模式

| 模式 id | 名称 | 用途 |
|---|---|---|
| `assist` | 辅助思考 | 找出资料间的联系，回答用户问题并给出建议 |
| `wander` | 思维漫游 | 结合资料与用户思考方向，发散联想、提出新视角 |
| `reflect` | 反思归纳 | 归纳用户可能没注意到的联系与盲点 |
| `plan` | 洞察规划 | 多轮 agent 推理，生成知识图表（canvas）或微课程（course）到库 |

- `assist` / `wander` / `reflect` 走 `POST /ask`，支持多轮对话（history 原样透传，仅最新问题参与检索）；
- `plan` 走 `POST /plan`：第一轮分析联系输出规划 JSON → 第二轮批判性反思补充遗漏 →
  第三轮按生成类型输出结构化 JSON（画布 nodes/edges 或课程 documents/sections/blocks），
  后端校验清洗后调用核心 API 创建文档集（kind=canvas / course），库文件本身即 `.mpf`，可直接导出。

## 4. 索引进度与自动建索引

- `POST /index` 在**后台线程**执行索引并立即返回本次启动的 key 列表；
- `GET /index/{key}/status` 返回 `{indexed, sectionCount, running, total, done}`，前端轮询显示进度条；
- **未建索引直接提问/规划**：`ask` / `plan` 返回 `409 + {"code": "NOT_INDEXED", "keys": [...]}`，
  前端自动触发建索引、显示进度条等待完成后重发请求。

## 5. 向量模型与一键下载

支持两个 Qwen3 embedding 模型（可在「第一步 · 建索引」页切换，切换会重启本地服务）：

| 模型 id | 说明 | 显存参考 |
|---|---|---|
| `Qwen/Qwen3-Embedding-0.6B` | 轻量、默认 | 约 2GB |
| `Qwen/Qwen3-Embedding-4B` | 更强，需更多显存 | 约 10GB+ |

下载与自动启动逻辑与原插件一致（多路尝试 ModelScope → HF-Mirror → HuggingFace，首次打开页面自动拉起），
见 `docs/05` 上一版的「部署本地 Embedding 服务」说明与 `scripts/kb_embedding_server.py`。

## 6. API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/plugins/ai_insight/resources` | 资源树（库 → 文档集 → 文档；软链接挂载），附各节点索引状态 |
| GET | `/api/plugins/ai_insight/resources/symlink/{mid}/tree?path=` | 浏览软链接挂载内目录 |
| GET | `/api/plugins/ai_insight/index/{key}/status` | 某数据源索引状态（含进行中进度） |
| POST | `/api/plugins/ai_insight/index` | 异步建索引，body `{"sources": [{"type", "id", "path?"}]}`，返回 `{started: [key]}` |
| POST | `/api/plugins/ai_insight/ask` | 多模式对话，body `{"sources", "mode", "question", "history?", "topK"}` |
| POST | `/api/plugins/ai_insight/plan` | 洞察规划，body `{"sources", "question", "output": "canvas"/"course", "libraryId?"}` |
| GET | `/api/plugins/ai_insight/modes` | 思考模式清单（id + 用途简述） |
| GET | `/api/plugins/ai_insight/embedding-status` | embedding 服务状态（含可选模型清单） |
| POST | `/api/plugins/ai_insight/embedding/start` | 启动/切换模型，body `{"model": "Qwen/Qwen3-Embedding-0.6B"}` |
| POST | `/api/plugins/ai_insight/embedding/stop` | 停止服务 |

`ask` 响应示例：

```json
{
  "answer": "根据[来源1]，傅里叶变换将信号从时域转换到频域。\n引用来源：[来源1]",
  "sources": [
    {
      "sectionId": "abc123", "sectionName": "傅里叶变换直觉",
      "docId": "def456", "docName": "第4章 频率域处理",
      "collectionName": "数字图像处理",
      "excerpt": "# 傅里叶变换直觉\n图像本质是...",
      "score": 0.8731,
      "link": { "kind": "learn", "collectionId": "col1", "sectionId": "abc123" }
    }
  ]
}
```

`plan` 响应示例：

```json
{
  "kind": "canvas",
  "collectionId": "col2",
  "collectionName": "信号处理概念图",
  "libraryId": "lib1",
  "summary": "傅里叶变换与卷积共同构成信号处理的核心。"
}
```

## 7. 故障排查

| 现象 | 处理 |
|---|---|
| 提问/规划返回 409 `NOT_INDEXED` | 前端会自动建索引并等待；也可到「第一步 · 建索引」手动执行 |
| 问答返回 503「本地 embedding 服务不可用」 | 检查服务是否启动：`curl http://127.0.0.1:8760/health`；确认 conda 环境已装 torch/transformers |
| 首次启动很久无响应 | 正在多路下载模型（ModelScope→HF-Mirror→HF），等待数分钟 |
| 软链接索引为空 | 确认所选路径下存在 `.md/.txt` 等白名单文本文件 |
| 规划生成的图表/课程内容异常 | AI 输出经后端清洗（节点必填字段、悬空边丢弃、非 markdown 块丢弃）；可重试或换更具体的规划目标 |

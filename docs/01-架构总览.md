# MetaPilot 架构总览

> 版本：1.0.0 · 项目仓库：见 README · 更新：随实现迭代

## 1. 项目定位

MetaPilot 是一个交互式学习网站。它同时是：

- **课程学习平台**：学习页以"组件流"呈现知识点，支持展示（Markdown）、题目（单选/多选/填空/简答，主观题由 AI 判分）、动态交互块（独立 HTML 页面，可内嵌物理模拟、可视化等）。
- **个人知识笔记**：导入 Markdown / Obsidian 格式的笔记进行浏览。
- **AI 洞察（插件）**：对"库-文件夹-文档-小节"与软链接本机目录多粒度向量编码，支持四类思考模式与洞察规划（生成图表/课程）。

## 2. 技术栈

| 端 | 技术 |
|---|---|
| 客户端 client | React 18 + Vite + TypeScript + Tailwind CSS + shadcn/ui + react-router + zustand + react-markdown + recharts |
| 后端 backend | Python 3.10+ + FastAPI + Pydantic v2 + uvicorn + httpx + numpy |
| AI 判题/问答 | MiniMax-M3（OpenAI 兼容接口 `https://api.minimaxi.com/v1`，模型名 `MiniMax-M3`） |
| 本地 Embedding | Qwen3-Embedding-0.6B + transformers，运行于 Conda 环境（默认 `Jyun`），后台子进程提供本地 HTTP 服务 |
| 数据存储 | 本地 JSON 文件（`backend/data/`），无需数据库 |

## 4. 核心数据模型（库-文件夹-文档-小节）

```
Library（库）──> Folder[]（文件夹）
Folder ──> Document[]（文档）
Document ──> Section[]（小节/知识点）
Section ──> Block[]（组件流）
```

术语映射：课程模式下 **文件夹=课程**、**文档=章节**、**小节=知识点**。集合的 `kind` 字段区分用途（`course` 课程 / `note` 笔记 / `kb` 知识库）。

Block（组件流单元）类型：

| type | 说明 |
|---|---|
| `markdown` | 展示块，Markdown 渲染 |
| `single_choice` | 单选题，本地判定 |
| `multiple_choice` | 多选题，本地判定 |
| `fill_blank` | 填空题，可走 AI 判题（`ai_graded: true`） |
| `short_answer` | 简答题，走 AI 判题 |
| `interactive` | 动态交互块，`file` 指向课程包内 `interactives/*.html`，iframe 沙箱加载 |

## 5. 本地存储设计

`backend/data/`：

| 路径 | 内容 |
|---|---|
| `libraries/{libId}.json` | 一个库一个文件，含全部内容（便于导入导出/单库备份） |
| `progress.json` | 学习进度：每课程独立，记录已学完小节与上次位置 |
| `stats.json` | 学习时长会话记录（开始/结束/时长/位置） |
| `assets/{collectionId}/` | 课程包资产（interactives 等原始 HTML），由后端静态托管 |
| `kb/` | 知识库向量索引（numpy `.npy` + 元数据 JSON） |

## 6. API 规划（前缀 `/api`）

- `GET /libraries`、`POST /libraries`、`GET/DELETE /libraries/{id}`
- `GET /libraries/{id}`（完整树）、`POST /libraries/{id}/collections`（创建课程/文件夹）、`GET/PUT/DELETE /collections/{id}`
- `POST /folders/{id}/documents`、`GET/PUT/DELETE /documents/{id}`
- `POST /documents/{id}/sections`、`GET/PUT/DELETE /sections/{id}`
- `POST /sections/{id}/blocks`、`PUT/DELETE /blocks/{id}`
- 进度：`GET/PUT /progress/{collectionId}`（completedSections、lastPosition）、`POST /progress/{collectionId}/toggle/{sectionId}`
- 统计：`POST /stats/sessions`（上报时长）、`GET /stats/summary?range=`
- AI：`POST /ai/grade`（判题）
- 插件/课程：`POST /api/plugins/course/import`（上传课程包）、`GET /api/plugins/course/{collectionId}/export`、`GET /api/plugins/course/assets/{collectionId}/{file}`（交互块托管）；学习进度 `/api/plugins/course/progress/*`、学习统计 `/api/plugins/course/stats/*`、AI 判题 `/api/plugins/course/ai/*`
- AI 洞察：`GET /api/plugins/ai_insight/resources`（资源树）、`POST /api/plugins/ai_insight/index`（异步建索引+进度）、`POST /api/plugins/ai_insight/ask`（四模式对话）、`POST /api/plugins/ai_insight/plan`（洞察规划生成图表/课程）

## 7. 插件机制

- 插件 = 后端 Python 包（`backend/plugins/<id>/`，`plugin.json` 为唯一元数据源，含 `specVersion`）+ 前端注册模块
  （`client/src/plugins/<id>/`：路由/导航/API 客户端集中声明）；开发规范见 [04-插件开发指南.md](04-插件开发指南.md)。
- 加载器 `app/plugins/loader.py` 扫描 `backend/plugins/` 自动加载，`base.py` 的 `PluginManager` 管理启用状态；
  路由统一前缀 `/api/plugins/<plugin_id>/`，被禁用时 `requires_plugin` 返回 503 + 启用提示。
- **课程插件（course）**：课程包导入/导出、学习进度/统计/AI 判题、交互块资产托管（全部位于 `/api/plugins/course/*`）。
- **AI 统一网关（核心 1.1.1）**：所有插件的 AI 调用经 `app.state.ai_gateway` 中转（chat/embed/rerank），
  支持 OpenAI 兼容 / Anthropic / 本地模型，密钥与地址存 .env 不出核心；每次调用记录 token 用量与成本（`统计 → AI 用量`）；
  设置页可配 provider/价格与一键下载内置模型（Qwen3-Embedding 0.6B/4B、Qwen3-4B、Qwen3-Reranker）。
- **AI 洞察插件（ai_insight）**：向量编码、余弦相似度检索、四类思考模式（辅助思考/思维漫游/反思归纳/洞察规划），
  洞察规划多轮推理生成图表/课程（`/api/plugins/ai_insight/*`），AI 调用走统一网关。详见 [05-AI洞察插件.md](05-AI洞察插件.md)。
- **软链接插件（symlink）**：挂载本机目录浏览/读写（`/api/plugins/symlink/*`），软链接视为库，在「我的库」页直接浏览（`/files` 保留为兼容入口）。
- **主题插件（themes）**：多套特色视觉主题（`/api/plugins/themes`）。

## 8. AI 能力

1. **主观题判分**：`/ai/grade` 接收题目类型、题干、参考答案、用户输入，调用 MiniMax-M3 输出结构化 JSON：`{score: 0-100, feedback, isCorrect}`。
2. **知识库问答**：检索 top-k 小节文本拼进上下文，由 MiniMax-M3 生成回答，同时返回命中的文档来源（含摘录），前端在对话中标出源。

所有 AI 调用经 `app/services` 封装，API Key 从 `.env` 读取，不硬编码。

## 9. 版本策略

- 当前版本 `1.0.0`。语义化版本：大核心修改（架构/数据格式变更）发布新版本；课程包 `manifest.json` 带 `formatVersion` 独立演进。
- 每次完成一个功能点即提交一次 commit，commit 信息中文描述该功能。

## 10. 运行方式（摘要，详见 README）

- 后端：`cd backend && pip install -r requirements.txt && python run.py`（默认 `127.0.0.1:8000`）
- 前端：`cd client && npm install && npm run dev`（默认 `5173`，代理 `/api` 到后端）
- 首次使用前复制 `.env.example` 为 `.env` 并填入 `MINIMAX_API_KEY`

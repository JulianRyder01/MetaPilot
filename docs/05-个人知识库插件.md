# 个人知识库插件

> 插件 id：`knowledge_base`。对"库-文档集-文档-小节"进行向量编码存储，支持 AI 提问并**溯源到每一个文档**（对话中标注 [来源N]，点击可跳转到对应知识点）。

## 1. 原理

```
小节文本 → Qwen3-Embedding-0.6B（本地）→ 向量(1024维)
用户问题 → 同模型编码 → 余弦相似度 top-k 检索
检索到的节选拼入提示词 → MiniMax-M3 生成回答（要求标注 [来源N]）
```

- 向量索引：`backend/data/kb/{collectionId}/vectors.npy` + `meta.json`（含文档名、小节名、摘录）
- 检索：归一化向量点积 = 余弦相似度

## 2. 部署本地 Embedding 服务

使用你的 Conda 虚拟环境（默认 `Jyun`）：

```bash
conda activate Jyun
pip install torch transformers
python backend/scripts/kb_embedding_server.py --port 8760
```

- 模型：`Qwen/Qwen3-Embedding-0.6B`（首次运行自动下载，约 1.5GB，缓存于 `~/.cache/huggingface`）
- 服务地址默认 `http://127.0.0.1:8760`，提供 `GET /health` 与 `POST /embed {"texts": [...]}`
- 也可以在知识库页面点「启动服务」由后端自动拉起（`conda run -n {CONDA_ENV} python ...`）

### .env 配置

```env
EMBEDDING_PROVIDER=local_transformers
EMBEDDING_URL=http://127.0.0.1:8760
EMBEDDING_MODEL=Qwen/Qwen3-Embedding-0.6B
CONDA_ENV=Jyun
```

`EMBEDDING_PROVIDER=none` 可禁用该插件（问答接口将返回 503）。

## 3. 使用流程

1. 打开「知识库」页面（顶栏导航）。
2. 选择课程 → 点「建立向量索引」（也可在课程页底部入口进入）。
3. 输入问题提问；回答中的 `[来源1]` 等标记可点击，下方列出命中的文档/知识点卡片（含摘录与相似度）。

## 4. API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/plugins/kb/embedding-status` | embedding 服务健康状态 |
| POST | `/api/plugins/kb/embedding/start` | 后台拉起本地 embedding 服务 |
| GET | `/api/plugins/kb/{cid}/status` | 索引状态 |
| POST | `/api/plugins/kb/{cid}/index` | 建立/更新向量索引 |
| POST | `/api/plugins/kb/{cid}/ask` | 问答，body `{"question": "...", "topK": 5}` |

`ask` 响应示例：

```json
{
  "answer": "根据[来源1]，傅里叶变换将信号从时域转换到频域。\n引用来源：[来源1]",
  "sources": [
    {
      "sectionId": "abc123", "sectionName": "傅里叶变换直觉",
      "docId": "def456", "docName": "第4章 频率域处理",
      "collectionName": "数字图像处理",
      "excerpt": "# 傅里叶变换直觉\n图像本质是...",
      "score": 0.8731
    }
  ]
}
```

## 5. 故障排查

| 现象 | 处理 |
|---|---|
| 问答返回 503「本地 embedding 服务不可用」 | 检查服务是否启动：`curl http://127.0.0.1:8760/health`；确认 conda 环境已装 torch/transformers |
| 首次启动很久无响应 | 正在下载模型，等待 1~10 分钟；可提前手动 `python scripts/kb_embedding_server.py` 观察进度 |
| 索引为空/失败 | 确认课程有内容；重新点「建立向量索引」 |
| 问答 400「尚未建立向量索引」 | 先执行索引 |

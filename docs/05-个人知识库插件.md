# AI 知识库插件（knowledge_base）

> 插件 id：`knowledge_base`。对**默认库（含课程/笔记）与软链接本机目录**多数据源建立向量索引，
> 支持 AI 提问并**溯源到具体内容**（对话中标注 [来源N]，点击跳转到对应知识点或文件浏览器）。
> 使用入口：顶栏导航「AI 知识库」。

## 1. 原理

```
数据源文本（库的小节 / 软链接文件的标题分段）
  → Qwen3-Embedding（本地，可选 0.6B / 4B）→ 向量
用户问题 → 同模型编码 → 余弦相似度 top-k 检索（支持多数据源合并）
检索到的节选拼入提示词 → MiniMax-M3 生成回答（要求标注 [来源N]）
```

- 索引按数据源独立存储：`backend/data/kb/{key}/vectors.npy` + `meta.json`，key = `library_<库id>` / `symlink_<挂载id>`
- 检索：归一化向量点积 = 余弦相似度

## 2. 数据源

| 类型 | 内容 | 索引单元 |
|---|---|---|
| `library`（默认库） | 库下的全部集合（课程/笔记/知识库）→ 文档 → 小节 | 每个小节一段 |
| `symlink`（软链接挂载） | 挂载根目录**递归**扫描文本文件（`.md/.markdown/.txt/.text/.rst`） | 按 Markdown 标题分段；无标题则整文件一段 |

页面「第一步 · 建索引」顶部**可多选**数据源，一并建立索引；问答「第二步 · 问 AI」可多选已索引源合并检索。

## 3. 向量模型与一键下载

支持两个 Qwen3 embedding 模型（可在「第一步 · 建索引」页面下拉切换，切换会重启本地服务）：

| 模型 id | 说明 | 显存参考 |
|---|---|---|
| `Qwen/Qwen3-Embedding-0.6B` | 轻量、默认 | 约 2GB |
| `Qwen/Qwen3-Embedding-4B` | 更强，需更多显存 | 约 10GB+ |

**下载（一键自动）**：服务启动时自动下载所选模型，多路自动尝试
`ModelScope → HuggingFace 镜像（hf-mirror.com）→ HuggingFace 官方`，缓存于各平台默认目录
（`~/.cache/modelscope` / `~/.cache/huggingface`）。首次下载 0.6B 约 2~3 分钟、4B 更久，页面每 5 秒自动刷新状态。

**自动启动**：配置 `EMBEDDING_AUTO_START=true`（默认）时，首次打开 AI 知识库页会自动拉起本地服务并下载模型；也可手动点「启动服务 / 停止服务」。

## 4. 部署本地 Embedding 服务

使用你的 Conda 虚拟环境（默认 `Jyun`）：

```bash
conda activate Jyun
pip install torch transformers modelscope huggingface_hub
# Qwen3-Embedding 需要较新的 transformers（>= 4.52），如已安装旧版请升级：
pip install -U transformers
python backend/scripts/kb_embedding_server.py --port 8760 --model Qwen/Qwen3-Embedding-0.6B
```

- 服务地址默认 `http://127.0.0.1:8760`，提供 `GET /health` 与 `POST /embed {"texts": [...]}`
- 也可由后端自动拉起（`conda run -n {CONDA_ENV} python ... --model {模型}`）

### .env 配置

```env
EMBEDDING_PROVIDER=local_transformers
EMBEDDING_URL=http://127.0.0.1:8760
EMBEDDING_MODEL=Qwen/Qwen3-Embedding-0.6B
CONDA_ENV=Jyun
EMBEDDING_AUTO_START=true
```

`EMBEDDING_PROVIDER=none` 可禁用该插件（问答接口将返回 503）。

## 5. 使用流程（两步）

1. 打开「AI 知识库」页面。
2. **第一步 · 建索引**：选择向量模型 →（必要时）点「启动服务」→ 勾选一个或多个数据源（默认库 / 软链接挂载）→ 点「建立向量索引」；每个数据源显示索引状态（已索引 N 段 / 未索引）。
3. **第二步 · 问 AI**：勾选已索引的数据源（可多选，合并检索）→ 输入问题；回答中的 `[来源N]` 可点击跳转（库来源 → 学习页知识点；软链接来源 → 文件浏览器对应挂载）。

> 必须先完成索引才能提问：未建索引时第二步会提示「请先在第一步建索引」。

## 6. API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/plugins/knowledge_base/sources` | 可用数据源（默认库 + 软链接挂载），附各源索引状态 |
| GET | `/api/plugins/knowledge_base/index/{key}/status` | 某数据源索引状态（key = `library_<id>` / `symlink_<id>`） |
| POST | `/api/plugins/knowledge_base/index` | 对多个数据源建索引，body `{"sources": [{"type": "library", "id": "..."}]}` |
| POST | `/api/plugins/knowledge_base/ask` | 多源问答，body `{"sources": [...], "question": "...", "topK": 5}` |
| GET | `/api/plugins/knowledge_base/embedding-status` | embedding 服务状态（含可选模型清单 models） |
| POST | `/api/plugins/knowledge_base/embedding/start` | 启动/切换模型，body `{"model": "Qwen/Qwen3-Embedding-0.6B"}` |
| POST | `/api/plugins/knowledge_base/embedding/stop` | 停止服务 |

`ask` 响应示例：

```json
{
  "answer": "根据[来源1]，傅里叶变换将信号从时域转换到频域。\n引用来源：[来源1]",
  "sources": [
    {
      "sectionId": "abc123", "sectionName": "傅里叶变换直觉",
      "docId": "def456", "docName": "第4章 频率域处理",
      "collectionName": "数字图像处理",
      "excerpt": "# 傅里叶变换直觉\n图像本质是...",
      "score": 0.8731,
      "link": { "kind": "learn", "collectionId": "col1", "sectionId": "abc123" }
    }
  ]
}
```

## 7. 故障排查

| 现象 | 处理 |
|---|---|
| 问答返回 503「本地 embedding 服务不可用」 | 检查服务是否启动：`curl http://127.0.0.1:8760/health`；确认 conda 环境已装 torch/transformers |
| 首次启动很久无响应 | 正在多路下载模型（ModelScope→HF-Mirror→HF），等待数分钟；可手动运行 `python scripts/kb_embedding_server.py` 观察进度 |
| 模型下载失败 | 检查网络；或手动下载后把 `EMBEDDING_MODEL` / 启动参数 `--model` 指向本地目录 |
| 软链接索引为空 | 确认挂载目录存在 `.md/.txt` 等白名单文本文件 |
| 问答 400「尚未建立向量索引」 | 先到「第一步 · 建索引」执行索引 |

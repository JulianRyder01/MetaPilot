# 插件开发指南

> MetaPilot 的功能以插件形式启用。基础是 Obsidian 风格的文件浏览器（库-文档集-文档-小节），课程、个人知识库等都是插件。本文说明如何开发新插件。

## 1. 插件机制

- 后端：每个插件是一个 Python 包（位于 `backend/app/plugins/<plugin_id>/`），继承 `base.Plugin`，在 `register(app)` 中挂载路由并初始化服务；插件清单通过 `GET /api/plugins` 暴露给前端。
- 前端：页面通过路由注册（`client/src/App.tsx` 中加 `<Route>`），导航入口加在 `AppLayout`。
- 插件启用 = 后端注册 + 前端入口存在。`enabled: true` 表示已注册。

## 2. 后端插件骨架

```python
# backend/app/plugins/my_plugin/__init__.py
from fastapi import FastAPI
from ..base import Plugin

class MyPlugin(Plugin):
    id = "my_plugin"
    name = "我的插件"
    version = "1.0.0"
    description = "插件做什么"

    def register(self, app: FastAPI) -> None:
        from ...api import my_plugin as api_mod   # 路由模块
        app.state.my_plugin = MyService(...)       # 挂到 app.state 供路由取用
        app.include_router(api_mod.router)

plugin = MyPlugin()
```

在 `backend/app/main.py` 注册：

```python
from .plugins.my_plugin import plugin as my_plugin
my_plugin.register(app)
register_plugin(my_plugin)
```

路由模块示例：

```python
# backend/app/api/my_plugin.py
from fastapi import APIRouter, Request
router = APIRouter(prefix="/api/plugins/my_plugin", tags=["plugins"])

@router.get("/ping")
def ping(request: Request):
    return {"ok": True}
```

## 3. 访问核心能力

- `request.app.state.store`：`LibraryStore`，库/文档集/文档/小节/块 CRUD（见 `app/storage/store.py`）
- `request.app.state.progress` / `request.app.state.stats`：进度与统计
- `request.app.state.importer`：课程包导入/导出
- `request.app.state.kb`：知识库服务（KBService：索引/检索/问答）
- `app/services/ai_grader.py`、`app/services/minimax.py`：MiniMax 判题与通用 chat 调用
- `app/services/embedding.py`：本地 embedding provider（Qwen3-Embedding-0.6B）

## 4. 前端插件页面

1. 在 `client/src/pages/` 新建页面组件。
2. 在 `client/src/App.tsx` 注册路由。
3. （可选）在 `client/src/components/layout/AppLayout.tsx` 增加导航入口。

## 5. 现有插件参考

|---|---|---|
| 课程 | `course` | 课程包导入/导出、资产托管（`/api/plugins/course/*`） |
| 个人知识库 | `knowledge_base` | 向量化、AI 问答与溯源（`/api/plugins/kb/*`），见 [05-个人知识库插件.md](05-个人知识库插件.md) |

## 6. 开发规范

- 插件 id 使用小写下划线，全局唯一。
- 路由前缀统一 `/api/plugins/<plugin_id>/`。
- 新插件必须写测试（`backend/tests/`，pytest + TestClient）。
- 依赖写入 `backend/requirements.txt`，敏感配置走 `.env`（模板追加到 `.env.example`）。
- 完成一个功能点提交一次 commit。

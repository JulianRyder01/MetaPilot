# 插件开发指南

> MetaPilot 的功能以插件形式启用。插件分为三类：**官方核心**（MetaPilot 本身，不可禁用/删除）、
> **官方插件**（官方开发，可选用/禁用，不可删除）、**用户自定义插件**（可开发、禁用、删除）。
> 本文说明如何开发新插件。

## 1. 插件机制

- 后端：每个插件是一个 Python 包（位于 `backend/app/plugins/<plugin_id>/`），继承 `base.Plugin`，在 `register(app)` 中挂载路由并初始化服务；插件清单通过 `GET /api/plugins` 暴露给前端。
- 前端：页面通过路由注册（`client/src/App.tsx` 中加 `<Route>`），导航入口加在 `AppLayout`。
- 插件启用 = 后端注册 + 前端入口存在。`enabled: true` 表示已注册。

## 2. 后端插件骨架（物理目录，自动加载）

```text
backend/plugins/my_plugin/
├── __init__.py      # 定义 plugin 实例
├── plugin.json      # 元数据（id/name/version/source/...）
└── routes.py        # 路由（带门禁）
```

```python
# backend/plugins/my_plugin/__init__.py
from fastapi import FastAPI
from app.plugins.base import Plugin

class MyPlugin(Plugin):
    id = "my_plugin"
    name = "我的插件"
    version = "1.0.0"
    description = "插件做什么"
    source = "user"            # core | official | user（用户自定义默认）

    def register(self, app: FastAPI) -> None:
        from .routes import router
        app.state.my_plugin = MyService(...)   # 挂到 app.state 供路由取用
        app.include_router(router)

plugin = MyPlugin()
```

```json
// backend/plugins/my_plugin/plugin.json
{
  "id": "my_plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "description": "...",
  "author": "你",
  "source": "user",
  "depends_on": []
}
```

启动时 `app/plugins/loader.py` 扫描 `backend/plugins/` 目录自动加载，**无需修改 main.py**。
路由始终挂载，被禁用时由 `requires_plugin` 依赖返回 503 + 启用提示：

```python
# backend/plugins/my_plugin/routes.py
from fastapi import APIRouter, Depends
from app.plugins.base import requires_plugin

router = APIRouter(
    prefix="/api/plugins/my_plugin",
    tags=["plugins"],
    dependencies=[Depends(requires_plugin("my_plugin"))],
)
```

## 3. 访问核心能力

- `request.app.state.store`：`LibraryStore`，库/文档集/文档/小节/块 CRUD（见 `app/storage/store.py`）
- `request.app.state.progress` / `request.app.state.stats`：进度与统计
- `request.app.state.importer`：课程包导入/导出
- `request.app.state.kb`：知识库服务（KBService：索引/检索/问答）
- `app/services/ai_grader.py`、`app/services/minimax.py`：MiniMax 判题与通用 chat 调用
- `app/services/embedding.py`：本地 embedding provider（Qwen3-Embedding-0.6B）

## 4. 前端插件页面

1. 在 `client/src/pages/` 新建页面组件。
2. 在 `client/src/App.tsx` 注册路由。
3. （可选）在 `client/src/components/layout/AppLayout.tsx` 增加导航入口。

## 5. 现有插件参考

| 插件 | id | 内容 |
|---|---|---|
| 课程 | `course`（official） | 课程包导入/导出、学习（进度/统计/AI 判题）、资产托管（`/api/plugins/course/*`） |
| 个人知识库 | `knowledge_base`（official） | 向量化、AI 问答与溯源（`/api/plugins/kb/*`），见 [05-个人知识库插件.md](05-个人知识库插件.md) |
| 主题 | `themes`（official） | 5 套特色视觉主题，`GET /api/plugins/themes` 返回 CSS 变量 |
| 软链接 | `symlink`（official） | 挂载本机目录作为文件系统浏览/读写（`/api/plugins/symlink/*`），前端文件浏览器页 `/files` |

## 6. 开发规范

- 插件 id 使用小写下划线，全局唯一；目录名 = id。
- 路由前缀统一 `/api/plugins/<plugin_id>/`；路由加 `requires_plugin` 门禁。
- `plugin.json` 声明 `source`（core/official/user）；用户插件可被 `DELETE /api/plugins/{id}` 删除。
- 新插件必须写测试（`backend/tests/`，pytest + TestClient）。
- 依赖写入 `backend/requirements.txt`，敏感配置走 `.env`（模板追加到 `.env.example`）。
- 完成一个功能点提交一次 commit。

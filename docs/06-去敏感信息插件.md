# 去敏感信息插件（desensitize）

本地脱敏工具：用**本机 ollama** 部署的小模型（默认 `qwen3.5:4b`，可在 UI 中任意修改）识别导入文档中的
敏感信息，插件内置**开放的替换/涂黑工具集**，把敏感内容替换/涂黑，并先**标出所有敏感信息供用户逐条确认**后再应用。

本插件为第三方插件，前端经 `frontend/frontend.js` 运行时动态加载（即插即用）；后端路由统一挂在
`/api/plugins/desensitize/*`。

## 前置：启动 ollama 并准备模型

1. 安装并启动本机 [ollama](https://ollama.com)（`ollama serve`，默认 `http://127.0.0.1:11434`）；
2. 在本插件页面「去敏感信息」里填写 ollama 地址与模型名（默认 `qwen3.5:4b`），点「保存配置」；
3. 点「拉取模型」把模型拉到本地（`ollama pull qwen3.5:4b` 的等效操作）——页面会显示就绪状态。

> 模型名、服务地址均可在配置中修改，插件不写死任何具体模型。其它内置本地模型（transformers、Qwen
> 向量等）可在「设置 → AI 服务」中独立管理，与 ollama 互不干扰。

## 工作流（demo）

1. **文本 / Markdown**：粘贴文本 →「分析敏感信息」→ 识别出的每个敏感段以红色高亮**标出**，并列出可勾选清单
   （含类型标签）→ 勾选（或全选）后「应用替换」→ 敏感内容被替换为黑色块（█），可复制脱敏结果。
2. **PDF**：上传 PDF → 自动提取文本并识别敏感信息（红色标出）→ 勾选后「按勾选内容涂黑文件」→ 下载
   高分辨率黑色块涂黑后的新 PDF（敏感文字所在区域被覆盖，文字层被清除）。
3. **图片**：上传图片（可选 OCR，未装 OCR 时降级为整张涂黑）→「按勾选内容涂黑文件」或「整张图片涂黑」→ 下载涂黑后的图片。

## 后端 API（开放工具集）

| 端点 | 说明 |
|---|---|
| `GET /api/plugins/desensitize/status` | ollama 状态：服务是否在线、当前模型、是否就绪、已拉取模型清单 |
| `POST /api/plugins/desensitize/config` | 保存 ollama 地址/模型到 `.env`（`AI_OLLAMA_URL` / `AI_OLLAMA_MODEL`） |
| `POST /api/plugins/desensitize/pull` | 拉取本地模型（阻塞至完成） |
| `POST /api/plugins/desensitize/analyze` | 识别文本中的敏感信息，返回定位后的条目（`items`，含 `start/end`） |
| `POST /api/plugins/desensitize/apply` | 按确认条目用黑色块替换文本/markdown，返回替换后文本与 `spans` |
| `POST /api/plugins/desensitize/file/analyze` | 上传 PDF/图片，提取文本→识别，返回条目与提取文本 |
| `POST /api/plugins/desensitize/file/redact` | 上传文件+确认条目，PDF 按内容涂黑 / 图片可整张或按矩形涂黑，返回新文件 |

工具分层：AI（ollama）只负责**识别并输出 JSON**（敏感段 `value` + `type`），具体替换/涂黑由插件内置
工具集执行（`mask_text` 文本替换、`redact_pdf` PDF 涂黑、`redact_image` 图片涂黑），因此识别所用
模型与具体工具解耦、可替换。

# 数据模型

> 基础结构：**库（Library） → 文件夹（Folder） → 文档（Document） → 小节（Section） → 组件块（Block）**

课程模式下术语映射：文件夹 = 课程，文档 = 章节，小节 = 知识点。库用于汇总一批相关文件夹。

## 1. 层次结构

```
Library（库）
└── Folder[]（文件夹 / 课程）
    ├── kind: course | note | kb
    ├── packageId: 课程包标识（用于同课程更新替换）
    ├── folders[]（文件夹树，可嵌套）
    │   ├── id, name, parentId
    │   └── 文件夹内可再含子文件夹与文档
    ├── documents[]（文档 / 章节，folderId 为空 = 根级）
    │   ├── docType: study | quiz | note
    │   ├── folderId: 所属文件夹（可选）
    │   └── sections[]（小节 / 知识点）
    │       ├── name
    │       ├── refDocId: 引用其他文档（可选，显示引用卡片跳转）
    │       └── blocks[]（组件流）
    │           ├── id, type
    │           └── 类型相关字段
```

> 类比：库 = 隔离环境（vault），文件夹 = 目录（可嵌套），文档 = 文件，小节 = 内容。
> 顶层文件夹（原「文档集」）承载 kind 内容类型（课程/图表/笔记）；嵌套文件夹为纯目录层级。
> 课程章节默认位于根级（folderId 为空），现有课程数据零迁移（旧 .mpf/.json 的 collections 键读取兼容）。

## 2. 组件块（Block）类型

| type | 字段 | 说明 |
|---|---|---|
| `markdown` | `content` | Markdown 展示（GFM 渲染） |
| `single_choice` | `question, options[], answer, explanation` | 单选题，本地判定 |
| `multiple_choice` | `question, options[], answers[], explanation` | 多选题，本地判定 |
| `fill_blank` | `question, blanks[], explanation, ai_graded` | 填空题；`ai_graded=true` 走 AI 判题 |
| `short_answer` | `question, reference, keywords[], explanation, ai_graded` | 简答题，AI 判题给出准确率 |
| `interactive` | `title, file, height` | 动态交互块，`file` 相对课程包 `interactives/`，iframe 沙箱加载 |

示例：

```json
{
  "type": "single_choice",
  "question": "灰度级数 L 与位数 k 的关系？",
  "options": ["L = 2k", "L = 2^k", "L = k^2", "L = k/2"],
  "answer": 1,
  "explanation": "8 位 → 256 级，即 L = 2^k。"
}
```

## 3. 本地存储布局（backend/data/，gitignore）

```
backend/data/
├── index.json                库摘要列表（列表接口用，避免读全量）
├── libraries/{id}.mpf        每个库的完整内容树（.mpf doc 类型；旧 .json 读取时自动迁移）
├── progress.json             学习进度（每课程独立）
├── stats.json                学习时长会话记录
├── assets/courses/{cid}/     课程包资产（interactives/*.html 等）
└── ai_insight/<key>/          AI 洞察向量索引（vectors.npy + meta.json，key=lib_/col_/doc_/sym_ 前缀）
```

> 库文件本身即 .mpf（MetaPilot 统一格式）：`{"format":"meta-pilot","formatVersion":1,"type":"doc", ...}`。
> .mpf 格式详见 docs/04-插件开发指南.md §11；doc 类型承载 库-文件夹-文档-小节，canvas 类型承载图表节点/连线。

## 4. 学习进度（progress.json）

```json
{
  "collections": {
    "<collectionId>": {
      "completedSections": ["<sectionId>", ...],
      "lastPosition": { "documentId": "...", "sectionId": "..." },
      "updatedAt": "..."
    }
  }
}
```

每课程独立缓存：已学完小节列表 + 上次学习位置。学完后大纲与课程页显示打勾。

## 5. 学习统计（stats.json）

```json
{
  "sessions": [
    {
      "id": "...", "collectionId": "...", "documentId": "...", "sectionId": "...",
      "startAt": "...", "endAt": "...", "durationSec": 125
    }
  ]
}
```

汇总接口支持 `all | today | week | month` 四种范围，输出总时长、每日分布、每课程分布。

## 6. 文件夹字段说明

```json
{
  "id": "05a22ccc4c57",
  "name": "数字图像处理",
  "kind": "course",
  "description": "...",
  "author": "MetaPilot",
  "version": "1.0.0",
  "formatVersion": 1,
  "packageId": "digital-image-processing",
  "createdAt": "...",
  "updatedAt": "...",
  "documents": [],
  "folders": []
}
```

- `kind`：课程包导入时为 `course`；笔记导入为 `note`；知识库文件夹为 `kb`
- `packageId`：课程包唯一标识；再次导入同一 `packageId` 的课程包时会**替换**旧课程（含资产）
- `formatVersion`：课程包格式版本，独立演进

## 7. 文件夹与引用 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/libraries/{lid}/folders` | 新建顶层文件夹 `{name, kind, description...}` |
| GET/PUT/DELETE | `/api/folders/{fid}` | 获取 / 更新 / 删除文件夹（顶层或嵌套，按 id 区分） |
| POST | `/api/folders/{fid}/folders` | 新建嵌套文件夹 `{name, parentId}` |
| PUT | `/api/folders/{fid}/canvas` | 保存图表画布（canvas 顶层文件夹） |
| PUT | `/api/documents/{did}` | 移动文档（`folderId`） |
| PUT | `/api/sections/{sid}` | 设置小节引用（`refDocId` 指向本文件夹内其它文档） |

> 旧路径 `/api/collections/...` 与 `/api/collection-kinds` 保留为别名（兼容历史调用与插件）。

小节引用渲染为引用卡片，点击跳转到目标文档；大纲中带「引用」徽章。
